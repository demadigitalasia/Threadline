# Glosarium Threadline

| Istilah | Definisi |
| --- | --- |
| Super Admin | Pengguna dengan akses penuh yang mengelola role dan status akses pengguna; Super Admin aktif terakhir tidak dapat diturunkan atau dinonaktifkan. |
| Finance | Pengguna yang mengelola jadwal dan catatan transfer secara terbatas, membaca rekap kewajiban, saldo, dan histori; tidak mengelola pekerjaan operasional. |
| Admin | Pengguna yang mengelola pekerjaan, memeriksa hasil, dan melihat rekap fee. Super Admin memiliki seluruh kewenangan Admin. |
| Freelance | Desainer yang menerima dan mengerjakan job. |
| Akun | Identitas yang digunakan satu orang untuk masuk ke Threadline. |
| Verifikasi email | Konfirmasi bahwa alamat email milik pengguna. |
| Profil | Data kerja yang mewakili seorang pengguna, termasuk nama tampilan dan peran. |
| Peran / Role | Jenis akses dan tanggung jawab pengguna; urutan role Threadline adalah Super Admin, Finance, Admin, lalu Freelance. |
| Nama kerja | Nama tampilan pengguna pada penugasan dan percakapan. |
| Job / Pekerjaan | Satu pesanan produksi jersey yang dikelola dari intake sampai ACC atau pembatalan. Istilah baku di dokumen: job. |
| Assignee / Penerima | Freelance yang ditugaskan pada job. |
| Pengalihan job | Pemindahan tanggung jawab job dari satu Freelance ke Freelance lain oleh Admin atau Super Admin. |
| Belum Ditugaskan | Status job yang belum memiliki penerima dan menunggu penugasan. |
| Antre | Job sudah ditugaskan dan menunggu mulai dikerjakan. |
| Dikerjakan | Freelance sedang mengerjakan job. |
| MintaACC | Freelance mengirim hasil untuk diperiksa Admin atau Super Admin. |
| Revisi | Admin atau Super Admin meminta perbaikan; Freelance perlu mengerjakan kembali. |
| ACC | Persetujuan final Admin atau Super Admin terhadap hasil; fee dan penerima job dibekukan. Fee masuk kewajiban saat job menjadi Finished. |
| Finished | Status setelah file asli diterima; tanggal `finished_at` menjadi dasar bulan fee timbul. |
| Dibatalkan | Status terminal untuk job yang tidak dilanjutkan. |
| Pengajuan hasil / Submission | Satu versi hasil yang dikirim untuk pemeriksaan ACC. |
| Arsip | Kumpulan job yang telah berstatus ACC dan tetap tersedia untuk dilihat kembali. |
| Timeline | Urutan aktivitas dan komentar yang terkait dengan job. |
| Thread chat | Percakapan langsung antara seorang Freelance dengan Admin dan Super Admin. Thread terpisah dari timeline job. |
| Presence | Penanda apakah seorang pengguna sedang online atau offline. |
| Express | Tingkat prioritas tinggi untuk job. |
| Urgen | Penanda bahwa job Antre telah mencapai batas waktu urgensi. |
| Terlambat | Penanda bahwa tenggat job telah tercapai atau terlewati sebelum job selesai atau dibatalkan. |
| SLA | Batas waktu layanan yang dipakai untuk menentukan kapan job Antre menjadi Urgen. |
| Fee | Nilai imbalan job yang disetujui saat ACC dan menjadi kewajiban setelah job Finished. |
| Transfer tercatat | Pembayaran manual yang dicatat Finance dengan tanggal transfer, referensi, bukti privat, dan alokasi ke satu atau beberapa job. Pencatatan tidak mengirim uang; jika catatan dibatalkan, histori tetap ada dan saldo dibalik pada bulan pembatalan. |
| Saldo kewajiban | Fee Finished dikurangi alokasi transfer yang masih berstatus tercatat; saldo dibawa ke bulan berikutnya. |
| Mode Demo | Mode untuk mencoba alur Threadline dengan data contoh. |
| Mode Online | Mode bersama tempat pengguna bekerja dengan data aplikasi. |
